# Introduction to Micro:bits

Welcome! I'm Paul, a software engineer at Red Hat. Over this workshop you'll go from never having coded a micro:bit to driving a radio-controlled car you programmed yourself.

You will be using this Tutors course throughout the workshop. Work through each lab step by step using the arrows or the menu on the left. If you get stuck, ask! Everyone gets stuck when they're coding, even professional developers.

## What is a micro:bit?

The micro:bit is a pocket-sized, programmable computer designed by the BBC to teach young people about coding and how software controls hardware.

You program it in **MakeCode**, a free website where you build code from blocks that snap together like puzzle pieces. When you're ready, you can switch the same code over to **JavaScript** or **Python** and see what "real" code looks like.

## The plan

| Part | What you'll do |
|------|----------------|
| 1. Introduction | Meet the micro:bit, set up MakeCode, download your first program |
| 2. Coding Basics | Events, the LED screen, variables, if/else, loops and functions |
| 3. Radio Communication | Send messages between two micro:bits and build a tilt remote |
| 4. Robot Car | Code a joystick remote and a car, then add power-ups and race |

## Objectives

By the end of this workshop you will be able to:
- Make the micro:bit react to inputs like buttons, shaking and tilting
- Use variables, if/else statements, loops and functions
- Send commands from one micro:bit to another using radio
- Code a working remote-controlled car
