# Controller Code

## Step 1: On start

In **on start**:
* **radio set group** to your team's number. Every team needs a **UNIQUE** radio group, and the car must use the same one!
* **initialise** the joystick (from the **Joystickbit** section)
* **show icon**, so you can tell the remote is switched on and running

![initialisejoystick](img/initialisejoystick.png)

## Step 2: How the joystick works

The **rocker value of X** and **rocker value of Y** blocks give you a number for the position of the stick, from roughly **0** to **1023**:

| Stick position | X | Y |
|----------------|---|---|
| Centre (resting) | ~525 | ~506 |
| Pushed **up** | ~525 | high (≥ 800) |
| Pulled **down** | ~525 | low (≤ 200) |
| Pushed **left** | low (≤ 200) | ~506 |
| Pushed **right** | high (≥ 600) | ~506 |

Every joystick is slightly different, so the centre won't be **exactly** 525/506. That's why we use **ranges** instead of exact numbers. Test yours with **show number** if you want to check.

## Step 3: Stop when the stick is centred

In a **forever** block, first check whether the stick is resting in the middle. If it is, send `"stop"` so the car doesn't drive off on its own:

![analog-atrest](img/analog_atrest.png)

The finished remote uses a slightly wider range for Y (**300 to 600**) so a little wobble won't make the car twitch.

## Step 4: Directions

Underneath, still inside **forever**, add an **if / else if** chain. **Do forward/reverse first!**

| If... | Send |
|-------|------|
| rocker Y ≤ 200 | `"B"` |
| else if rocker Y ≥ 800 | `"F"` |
| else if rocker X ≤ 200 | `"L"` |
| else if rocker X ≥ 600 | `"R"` |
| else if button **A** is pressed | `"stop"` (emergency stop!) |

Example of the reverse condition:

![backwards](img/backwards-controller.png)

## Step 5: Test it

Use the **Radio** lab's trick: flash a spare micro:bit with a receiver that shows an arrow for each message. Or wait until your teammate's car is ready!

<summary>Check your work: the finished remote</summary>

Change the `10` to your team's radio group.

```javascript
radio.setGroup(10)
joystickbit.initJoystickBit()
basic.showIcon(IconNames.Heart)
basic.forever(function () {
    if (joystickbit.getRockerValue(joystickbit.rockerType.X) >= 500 && (joystickbit.getRockerValue(joystickbit.rockerType.X) <= 550 && (joystickbit.getRockerValue(joystickbit.rockerType.Y) >= 300 && joystickbit.getRockerValue(joystickbit.rockerType.Y) <= 600))) {
        radio.sendString("stop")
    }
    if (joystickbit.getRockerValue(joystickbit.rockerType.Y) <= 200) {
        radio.sendString("B")
    } else if (joystickbit.getRockerValue(joystickbit.rockerType.Y) >= 800) {
        radio.sendString("F")
    } else if (joystickbit.getRockerValue(joystickbit.rockerType.X) <= 200) {
        radio.sendString("L")
    } else if (joystickbit.getRockerValue(joystickbit.rockerType.X) >= 600) {
        radio.sendString("R")
    } else if (input.buttonIsPressed(Button.A)) {
        radio.sendString("stop")
    }
})
```

## Extra challenges

* Use the coloured buttons on the Joystick:bit (look for the button blocks in the **Joystickbit** section) to send extra commands, like a horn or a spin move. Your teammate will need to add them to the car too!
* Show an arrow on the remote's LEDs for the direction you're sending.
