# Power-ups

Mario Kart, but real

Your car can drive. Now let's make racing more interesting! Each car has an **RFID reader** underneath, and there are **power-up cards** hidden around the track. Drive over one and something happens:

| Card | Power-up | What happens |
|------|----------|--------------|
| 🍄 Boost | `speedUp` | Happy face, full speed (100) for 2 seconds |
| 🍌 Banana | `banana` | Silly face, "uh-oh" sound, the car **spins out** for 2 seconds |
| 🐢 Slow | `slowDown` | Sad face, crawls along at half speed (50) for 2 seconds |

While a power-up is happening, **your remote stops working**. No steering out of a banana spin!

## What is RFID?

**RFID** (Radio Frequency IDentification) is the same technology as your bus card, a contactless payment card, or a shop's security tag. Each card has a tiny chip with a **unique ID number**. When the card comes close to a reader, the reader powers the chip using radio waves and reads its number.

The car's code knows which ID numbers belong to which power-up.

## Get the code

The RFID reader needs some extra low-level code to talk to it, so you'll start from a ready-made project rather than from scratch:

1. Open the [RFID car project](https://makecode.microbit.org/S97008-07416-41442-62980)
2. Click **Edit Code** to make your own copy
3. In **on start**, change the **radio set group** number to **your team's number**
4. Download it to your car's micro:bit

Your remote doesn't need to change at all. It sends the same `"F"`, `"B"`, `"L"`, `"R"` and `"stop"` messages as before.

> **Note:** the banana sound needs a **micro:bit V2** (the one with a speaker). On a V1 everything else still works.
