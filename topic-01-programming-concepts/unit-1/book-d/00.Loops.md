# Loops & Functions

Repeating yourself without repeating yourself

## Loops

A **loop** repeats code so you don't have to copy the same blocks over and over. Loops are in the **Loops** (green) section:

| Block | What it does | Use it for |
|-------|--------------|------------|
| **forever** | Repeats until the micro:bit is switched off | Constantly checking a sensor or joystick |
| **repeat 4 times** | Repeats an exact number of times | Flashing a light 3 times |
| **while ... do** | Repeats **as long as** a condition is true | "While button A is **not** pressed, beep" |
| **for index from 0 to 4** | Repeats, counting up in a variable called `index` | Lighting up a row of LEDs one by one |
| **every 500 ms** | Runs every so often, in the background | A blinking light that doesn't stop other code |

### Example: flash a heart 3 times

```python
for i in range(3):
    basic.show_icon(IconNames.HEART)
    basic.pause(200)
    basic.clear_screen()
    basic.pause(200)
```

### Example: light up the top row, one LED at a time

```python
for index in range(5):
    led.plot(index, 0)
    basic.pause(100)
```

`index` goes 0, 1, 2, 3, 4, so the LEDs light up from left to right.

> **Watch out:** a **while** loop whose condition never becomes false runs **forever**, and nothing after it will ever run!
